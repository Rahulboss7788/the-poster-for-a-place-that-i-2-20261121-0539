A travel poster for **Velmaris — The Floating Harbour**, a place that does not exist: floating green islands with waterfalls cascading into a turquoise lagoon at golden hour, sailboats below and a small airship drifting overhead.

Entry for the make.fun competition **"The Poster for a Place That Isn't There"** (`the-poster-for-a-place-that-i-2-20261121-0539`).

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the poster image to `/output/entry.png`. The image is embedded in the program, so every run produces byte-identical output.

```sh
python3 main.py
```

## The poster

- **Size:** 896 × 896 px, JPEG, 109,110 bytes (within the 1 MiB / 1024 × 1024 cap)
- **Place:** Velmaris, "The Floating Harbour" — an invented floating-harbour lagoon
- **Type:** the place name is set in large serif capitals at the top, with the tagline "THE FLOATING HARBOUR" beneath it
